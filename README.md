These are **five different original procedural car designs**, with geometry generated by `src/build_original_cars.py`. No Porsche models, game rips, commercial OEM badges, or third-party mesh assets are used.

### Build

```bash
pip install -r requirements.txt
python src/build_original_cars.py
```

Generated model files and their SHA256 validation report are stored in `src/models/` by the source script and are committed to `vehicles/` by the GitHub Actions workflow. Check the workflow log if GLBs do not yet exist.

### Model features

- Distinctive silhouettes, physical scale in meters, four rotating-wheel assembly groups, custom alloy wheels and brake discs.
- Cockpit structures, seats, dashboard and steering wheel; visible mechanical systems appropriate to each architecture.
- Original PBR material parameters for paint, glass, rubber, metals, lights, fabric, engine and brakes.
- Approximately 77k–86k triangles per car; batched geometry by material while separating four wheel groups for future rigging.

### HONEST QUALITY & RELEASE STATUS

**PROTOTYPES, NOT AAA PHOTO-REAL VEHICLES.** Structural and basic projected-view inspections have been performed, but these assets do not yet satisfy full photorealism, correct functional door seams, production physics rigs, detailed OEM-level engine bays, texture atlases, UV authoring, professionally optimized LODs, nor Unreal 5.7 in-game quality QA.

**NOT LEGALLY APPROVED FOR COMMERCIAL RELEASE YET.** Original fictional meshes and names are safer than Porsche knockoffs, but there is no legal guarantee. Trademark searches, protected-design similarity review, vehicle naming review, and IP counsel signoff remain outstanding.
